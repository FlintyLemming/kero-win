# Workspace Rules (kero-win)

- **Sync documentation on every feature or behavior change**:
  - Whenever you add, modify, or remove user-facing features, settings, shortcuts, CLI flags/commands, or fork-specific behavior, update [README.md](README.md) (especially the `## 已修改内容` section) in the same task before finishing.
  - Also update the modification ledger in [PATCHES.md](PATCHES.md) (overview table + detail section + upstream conflict resolution notes) to keep all local fork customizations traceable.
- **Release checklist**: Follow [RELEASING.md](RELEASING.md) when cutting a release.
